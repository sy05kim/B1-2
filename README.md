# 1. 브랜드 아이덴티티

- **브랜드명**: CORE
- **타겟**: 미래 기술, 친환경 에너지, 프리미엄 전자제품에 관심 있는 전 연령대
- **톤앤매너**: 미래적, 고급스러운, SF, 푸른 에너지, 시네마틱
- **USP**: 작은 배터리 하나로 도시 전체를 움직일 수 있는 차세대 에너지 기술
- **핵심 메시지**: 작은 코어 하나가 거대한 에너지를 만든다.
- **슬로건**: “충전은 끝났다.”
- **광고 콘셉트**: 손 안의 작은 핵융합 배터리가 도시 전체를 깨우고, 충전이 필요 없는 미래 에너지의 시작을 보여주는 10초 브랜드 광고

# 2. 제작의도

본 영상은 미래형 핵융합 배터리 브랜드 CORE를 홍보하기 위한 짧은 광고 영상이다.
기존 배터리는 충전이 필요하지만, CORE는 핵융합 에너지를 기반으로 한 무한동력에 가까운 차세대 배터리라는 설정을 가지고 있다.

광고는 총 3개의 장면으로 구성하였다.
초반에는 손 위에 놓인 작은 제품을 보여주고, 중반에는 그 에너지가 미래 도시 전체로 확산되는 모습을 보여준다. 마지막에는 브랜드명과 슬로건을 제시하여 광고 메시지를 명확하게 전달한다.

전체적인 분위기는 어두운 배경과 푸른빛 에너지를 중심으로 연출하여, 제품이 가진 첨단 기술성과 프리미엄 이미지를 강조하였다.
